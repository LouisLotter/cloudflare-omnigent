S6 qualification: attacker page

This page stands in for a malicious site, for spike S6's IR-010 qualification. It sends the requests a hostile page could send to the S6 staging page, in your logged-in browser: from another origin (this page), from a null origin (a sandboxed frame), as a simple form, as a WebSocket to the terminal, and as a top-level link. It cannot see the answers. Every attempt carries a case= tag, so the S6 page's Q5 Qualification report shows which ones reached the Worker and why each was refused.

Target:

  1. Start the synthetic computer first (S6 page, Q2).
  2. This page runs its automatic attempts on load (below).
  3. Then click this link once; it must show a page that says "This page changes nothing". Do not press its button. Close that tab: top-level cross-site GET of a control URL
  4. Go back to the S6 page and click Q5 Qualification report. The synthetic computer must still be running, with the same generation.
