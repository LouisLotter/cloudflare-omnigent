# User manual

This manual is for the people who use an Omnigent installation: the members of a team, and the owners and administrators who look after it. It assumes no technical background. Everything it describes is done on a web page; nothing here asks you to type a command.

If you are the person who installs and runs the installation itself, start with the [install guide](../install.md) instead.

## What you are using

An installation is one Omnigent, run in its owner's own Cloudflare account, for one team. You reach it at its web address. Two kinds of page live there:

- **Omnigent itself**, where you start sessions with an agent, follow their work, share them, answer approvals and change your settings. A session is one conversation with an agent and the work it does; other tools call it a thread.
- **The computers pages** (`/platform/computers`), where you set up your cloud computers: you sign in to Claude or Codex there, and you can open a terminal on the computer if you ever need one. Each page has a **Help** link back to this manual.

Each person in the team has their own cloud computers and their own Claude or Codex subscription. A session runs on a computer that belongs to you, with your subscription. Nobody else's subscription is used for your work, and yours is not used for theirs, unless someone shares a session with editing rights (see [Sessions and sharing](threads-and-sharing.md)).
